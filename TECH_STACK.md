# Tech Stack Project Capstone 2.0

Berikut adalah ringkasan teknologi dan *library* utama yang digunakan dalam proyek ini berdasarkan `composer.json` dan `package.json`:

## Backend
- **Framework**: Laravel 12.x
- **Bahasa Pemrograman**: PHP 8.2+
- **Autentikasi**: Laravel Sanctum & Laravel Breeze
- **Real-time Server**: Laravel Reverb

## Frontend
- **Templating Engine**: Laravel Blade
- **CSS Framework**: Tailwind CSS 4.3+
- **JavaScript**: Alpine.js
- **Build Tool**: Vite 6.0+

## Integrasi & Library Tambahan
- **Payment Gateway**: Midtrans (`midtrans/midtrans-php`)
- **Progressive Web App (PWA)**: ERAG Laravel PWA
- **Real-time Client**: Pusher JS & Laravel Echo
- **QR Code Generator**: Simple QrCode
