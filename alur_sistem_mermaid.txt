1. ALUR ROLE OWNER / ADMIN
====================================
%%{init: {"flowchart": {"defaultRenderer": "elk"}}}%%
flowchart TD
    Start([START]) --> Login[/Input Email & Password/]
    Login --> CekLogin{Kredensial Valid?}
    CekLogin -- Tidak --> ErrLogin[/Tampilkan Error/]
    ErrLogin --> Login
    CekLogin -- Ya --> DashAdmin[Tampil Dashboard Admin]
    
    DashAdmin --> PilihMenu{Pilih Aksi?}
    
    PilihMenu -- Kelola Kamar --> Kamar[Tambah/Edit/Hapus Kamar]
    Kamar --> GenerateQR[Buat QR Code Kamar]
    GenerateQR --> SimpanDB[(Database)]
    
    PilihMenu -- Kelola Kategori --> Kategori[Tambah/Edit/Hapus Kategori]
    Kategori --> SimpanDB
    
    PilihMenu -- Kelola Menu --> Menu[Tambah/Edit/Hapus Menu]
    Menu --> UploadImg{Upload Gambar?}
    UploadImg -- Ya --> ImgBB[Kirim ke ImgBB & Dapatkan URL]
    ImgBB --> SimpanDB
    UploadImg -- Tidak --> SimpanDB
    
    SimpanDB --> Logout[Logout]
    PilihMenu -- Logout --> Logout
    Logout --> Stop([STOP])

4. ALUR ROLE USER / GUEST (WEBSITE)
====================================
%%{init: {"flowchart": {"defaultRenderer": "elk"}}}%%
flowchart TD
    Start([START]) --> Scan[/Scan QR Code di Kamar/]
    Scan --> Validasi{URL Kamar Valid?}
    Validasi -- Tidak --> ErrURL[/Tampilkan Error 404/]
    ErrURL --> Stop([STOP])
    
    Validasi -- Ya --> Web[Tampil Halaman Web Katalog]
    
    Web --> Pilih[Pilih Menu Makanan/Minuman]
    Pilih --> Cart[Masukkan ke Keranjang]
    
    Cart --> TambahLagi{Tambah Pesanan Lain?}
    TambahLagi -- Ya --> Pilih
    TambahLagi -- Tidak --> Checkout[Klik Checkout]
    
    Checkout --> Form[/Isi Catatan & Detail Pembayaran/]
    Form --> ValidasiPay{Pembayaran Berhasil?}
    
    ValidasiPay -- Tidak --> ErrPay[/Notifikasi Gagal Saldo Kurang/]
    ErrPay --> Form
    
    ValidasiPay -- Ya --> Sukses[/Tampilkan Struk & Nomor Antrean/]
    Sukses --> PushDB[(Notifikasi Pesanan ke Kitchen)]
    PushDB --> Stop
